# Google Business Profile — operator checklist

Nothing here has been done. Changes to Google profiles are a separate order. Check
Google’s current official guidelines (business name, representation, merging) right
before any change — rules change often.

## Access

- [ ] Find out which Google account owns each existing profile
- [ ] Owner/manager access for both stores secured (no shared passwords)

## Per store (Chaweng, Fisherman’s Village)

- [ ] Business name exactly as on the **real signage** at that store (not just the website name)
- [ ] Address and map pin match the store’s actual location — same as on the website
- [ ] Opening hours identical to the website
- [ ] Phone / WhatsApp identical to the website
- [ ] Category (e.g. tailor / clothing store) checked
- [ ] Website link points to the store page:
      `https://<domain>/en/stores/chaweng` and `https://<domain>/en/stores/fishermans-village`
- [ ] Own, current photos (facade, interior, team) — same approval rules as the website

## Rename / merge

- [ ] Do **not** rename or merge profiles automatically
- [ ] Rename only after the signage has changed; keep the two stores as two profiles
- [ ] Existing reviews stay with their profile — no combined rating on the website
- [ ] After renaming: activate `/our-new-name` (`brand.transition.active = true`)
